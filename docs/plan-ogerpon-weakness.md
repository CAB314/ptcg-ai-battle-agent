# Ogerpon の弱点克服（対 Kangaskhan / 対 Grimmsnarl）— 考察と計画（2026-08-06）

## 0. 現状の実測（8/6 判定データより）

| 対面 | v0（BCのみ） | v1（PPO後） | 読み |
|---|---|---|---|
| vs grimmsnarl_ppo2 | **91.1%** | 92.0% | v0時点で既に9割 = **デッキ構造の優位**（リーグ過適合ではない） |
| vs kangaskhan | **0.7%** (n=875) | 2.2% | BC（人間譲りの方策）でもほぼ全敗 = 構造疑い。ただし下記の交絡あり |
| field（v0盤・8/5加重） | 64.3% | 69.1% | 6アーキ中の最強。穴は kangaskhan に集中 |

重要な事実: round 1 のリーグには kangaskhan が w=0.121 で入っており、PFSP は
負けている相手を自動過重する（EMA≈0 → ほぼ最大重み）。**それでも 0.7→2.2% にしか
動かなかった**。勝率≈0 の対面は正報酬の軌跡がほぼ得られず、**勾配の信号が消える**
（sparse-reward）。つまり「リーグに入れて回すだけ」では克服できないことは実証済み。

## 1. まず答えるべき問い: 壁は「デッキ」か「方策」か

2.2% が argmax 同士の決定論的な轍（同じ負け筋を毎回なぞる）なのか、
デッキ相性の壁なのかで打ち手が全く変わる。**診断を先に行う（Phase 0、CPUのみ・約1時間）**:

1. **人間ベースライン**: 手元の50日分エピソードから ace×ace 勝率行列を作り、
   実ラダーの Ogerpon vs Kangaskhan を測る。
   - 人間が 35–45% 取れている → 方策問題（学習で回収可能）。
   - 人間も 10–20% → 相性の壁（デッキテック or 許容）。
2. **温度プローブ**: argmax でなく T=1.0 サンプリングで ogerpon v1 vs kangaskhan v1 を
   400戦。勝率が 2%→10%超に跳ねるなら「決定論の轍」で、**勝ち筋は方策の中に眠っている**
   （PPO の探索設定で回収しやすい）。
3. **クロスパイロット格子**: {ogerpon デッキ} × {v1 / v0 / greedy_lethal2} vs
   {kangaskhan v1 / playbook2 / greedy} 各400戦。どのパイロットでも≈0%なら構造説が濃い。
4. **負け筋の定性分析**: 敗戦リプレイ20件の要約（決着ターン・サイド推移・何が何に倒されるか）。
   例えば「Mega Kangaskhan ex を一度も倒せていない」なら打点不足＝デッキ問題。

## 2. 打ち手A: 方策の強化（Phase 0 が「方策問題」と出た場合）

専用 run（ppo_opp_ogerpon_v2k）を1本、通常の round 2 とは別に回す:

- **リーグ過重**: fixed の kangaskhan セルを w×5（実効 ~40%）+ grimmsnarl w 維持。
- **探索温度**: 対 kangaskhan ゲームのみ sample_temperature を 1.0→1.3 に上げる
  （actor はセル毎に spec を持つので、league セルに temperature を持たせる小改修）。
- **教師シード（任意・データ量次第）**: 実ラダーで「Ogerpon が Kangaskhan に勝った」
  ゲームの決定だけ抽出し、v1 を1–2 epoch だけ BC 微調整してから PPO
  （人間の勝ち筋を初期値として注入）。データが数千決定あれば実施。
- **合否ゲート（事前登録）**:
  1. vs kangaskhan v1 ≥ **20%**（2.2%からの回収の第一目標。SE±2ppで判別可能）
  2. field（v1盤）が現行 v1 比 **−1pp 以内**（他対面を壊さない）
  3. vs grimmsnarl_ppo2 ≥ 85% を維持
- コスト: GPU 約3h（1本）。失敗しても v1 に据え置くだけ。

## 3. 打ち手B: デッキの強化（Phase 0 が「構造問題」と出た場合）

- 上位 Ogerpon パイロット（keidroid 60.3% / Rmy 58.0% など）の最頻リストと
  我々の deck.csv の差分から候補を生成（mewtwo で実証済みの手順 =
  make_ablation_v2_spec.py の流用）。
- 対 Kangaskhan テックの仮説候補を含め、**kangaskhan を w 0.4 に過重した field** で
  deck_ablation を回す（CPU のみ、13万戦 ≈ 25分）。
- 判定: 対 kangaskhan の改善 ≥ +10pp かつ全体 field で −1pp 以内。
- 注意: 方策は ogerpon デッキで学習済みのため、大きなデッキ変更は方策不慣れの
  バイアスが乗る（保守的に効く）。プラスが出れば本物。

## 4. 対 Grimmsnarl の「強化」について

92% は既に構造優位で、これ以上の直接強化は限界効用が小さい。やるべきは**頑健性の確認**:
- grimmsnarl の別パイロット（grimmsnarl_ppo / bc3 / ルール勢）3種 × 各600戦で
  85% 以上を維持できるか（= 対 ppo2 特化ではないことの確認）。
- 本当の試験は実ラダー（他チームの Grimmsnarl は我々の ppo2 より強い可能性）。
  提出するなら初日のマッチアップ内訳を必ず確認する。

## 5. 正直な見立て

- **0.7–2.2% は「数ppの上積み」ではなく崖**。人間ベースラインが低ければ、
  克服ではなく**許容**（kangaskhan はメタ12%。field 期待値では ogerpon が依然最強）が合理的。
- 一方、温度プローブで勝率が跳ねる／人間が4割取れているなら、打ち手Aの回収は
  速い（sparse-reward が解ければ PPO は既に5対面で実証済みの伸び方をする）。
- 提出判断（8/16 枠）は本計画の結果を**待たなくてもよい**: ogerpon v1 のまま
  「対 kangaskhan を捨てる」構えでも field 69.1% で最強。克服できれば上積み。

## 6. P0 診断結果（2026-08-06 19:30 実施）

| 診断 | 結果 | 含意 |
|---|---|---|
| P0.1 人間ベースライン（50日・517,594サイド） | **Ogerpon vs Kangaskhan = 24.9%** (n=401)。参考: vs Grimmsnarl 83.7% (n=1,648) | 壁は25%にあり2%ではない。**約23ppの回収余地** |
| P0.2 温度プローブ（T=1.0, 400戦） | **1.2%**（argmax 2.2% と同水準以下） | 勝ち筋は方策の近傍に**無い**。探索を上げるだけの PPO は効かない |

**確定診断**: 「決定論の轍」ではなく「方策の欠落」。人間は25%取れる勝ち筋を持つが、
我々の方策はその線を全く持っていない（摂動しても出てこない）。
→ **打ち手Aを改訂**: 主レバーは「人間の勝ちゲームによる BC シード」。
  シャード内の Ogerpon 勝ち vs Kangaskhan は約100ゲーム（~1–2万決定）。
  これを一般データと混ぜて v1 を軽く微調整 → kangaskhan 過重リーグで PPO、の順。
  過重リーグ単独（w×5）は round 1 の実測（0.7→2.2%）から効果薄と予想。
  副案: 勝ちゲームの教師リスト（デッキ）が我々と違う場合はデッキテック（打ち手B）併用。
**現実的な目標**: vs kangaskhan 2.2% → **15–25%**（人間水準が上限の目安）。
field 期待値では +1.5〜2.8pp 程度の上積みに相当（シェア12%）。
